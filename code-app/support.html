Code Timer — Support

Code Timer is a clinical reference and memory aid for nurses and other licensed healthcare professionals: a BLS/ACLS/PALS code timer, weight-based pediatric doses, IV mixing cards, hemodynamic, ABG and ventilator calculators.

Contact

Questions, bugs, or a dose that looks wrong: open an issue on GitHub. Reports of a possible dosing error are handled first.

Common questions

No sound on alerts? Turn up the volume. Alarms play even with the silent switch on.

Lost a code log? The log stays until you tap Reset. Copy it into your charting before resetting.

Where do the doses come from? In the app: Ref → About & sources.

Important

Code Timer is not a medical device and does not replace clinical judgment, provider orders, pharmacy or facility protocol. Check every dose against the order and the product in hand.
