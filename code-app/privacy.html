Code Timer — Privacy Policy

Effective November 21, 2026

Short version

Code Timer collects nothing. No account, no analytics, no ads, no tracking, and nothing you type is sent anywhere.

What stays on your phone

  • The current code log, timers and the weight you enter, so a code isn't lost if the app closes. Tapping Reset erases it.
  • Your display setting (light/dark) and that you've seen the disclaimer.

This is stored only on your device, in the app's own storage. It is never uploaded, shared or sold. Deleting the app deletes it.

Patient information

Don't enter names or other identifying patient details. The app has no field that asks for them.

Third parties

None. The app makes no network requests while you use it.

Children

The app is a clinical reference for healthcare professionals and isn't directed at children. It collects no data from anyone.

Changes and contact

If this policy changes, the new version will be posted on this page. Questions: support page.
