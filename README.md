# Claude

## code-app/ — BLS/ACLS code timer + fever med dosing

Single file (`code-app/index.html`). Open it in any phone browser; no install, works offline.
On iPhone: Share → Add to Home Screen to make it look like an app.

- **Code tab** — code clock, 2-min CPR cycle with pulse/rhythm check alert (warning at 15 sec left),
  epi timer (due at 3 min, overdue at 5), shock / amiodarone / lidocaine tracking, BLS or ACLS mode,
  110/min metronome, H's & T's, timestamped event log (military time) you can copy.
- **Fever meds tab** — enter weight in kg or lb; shows acetaminophen and ibuprofen doses in mg and mL.
- **Reference tab** — BLS CPR numbers, ACLS doses, post-ROSC targets.

Memory aid only. Verify against the current AHA manual and facility protocol.
